Privacy Policy

AthenaWS Cloud Backup is a personal application used by its owner to download and preserve copies of files from authorized cloud accounts.

The application uses rclone and Google's APIs to access files with the account owner's authorization. Downloaded files are stored on the owner's local drive.

The application does not intentionally sell or distribute Google account data to third parties. OAuth credentials are stored locally in the owner's rclone configuration.

This informational website does not request Google credentials or upload cloud files. GitHub Pages hosts the public website.
